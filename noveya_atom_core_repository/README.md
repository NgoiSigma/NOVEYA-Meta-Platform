# NOVEYA-ATOM-Intelligent-Transport-Dispatcher-Terminal-Core
Система нормирования расхода ресурсов и расчета оплаты/учета труда в общинах (громадах) по методике НРМ и макету Формальной Диалогики (-FDL).

## Структура репозитория
* `NoveaAtomEngine.py` — Ядро расчета истинной трудоемкости (Tr), нормативов ресурсоемкости (NR) и интеграции с PayPal API.
* `NoveaClearingEngine.py` — Модуль двустороннего хозяйственного и сырьевого клиринга (бартер щепы).
* `test_novea_atom_engine.py` — Модуль автоматизированных юнит-тестов (PyTest) для симуляции телеметрии и PayPal Sandbox.
* `test_clearing.py` — Тесты верификации сырьевого клиринга.
* `NoveaAtomEngine.hpp` — Высокопроизводительный вычислительный C++ узел для расчета метрик FDL.

## Развертывание
1. Установите зависимости: `pip install pytest requests`
2. Запустите тесты: `pytest . -v`
